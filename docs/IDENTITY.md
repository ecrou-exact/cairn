# Name and logo — proposals

> Status: **decided 2026-11-21 — name Cairn, logo direction A (D-014)**. Former working name (`PROJECT_BRIEF.md` §14.2). Drafts only; the chosen direction gets a full set (SVG light/dark, PNG sizes, favicon) in Phase 2.

## Why rename
"Claude Manager" uses Anthropic's product name. For a public open-source project, a name that does not depend on a vendor trademark is safer and lets the app support other agents later. The repo can be renamed on GitHub at any time (old URLs redirect).

## Name options
Availability (GitHub org, PyPI, domain) still to check for the shortlisted one.

| Name | Idea | Notes |
|---|---|---|
| **Cairn** | stacked stones that mark a path: tasks stacked on their dependencies, guiding the way | short, memorable, fits the graph + plan idea |
| **Waymark** | a marker on a route; the app tells you what to do next | descriptive, slightly longer |
| **Keel** | the spine that keeps the boat steady and on course | very short; common word |
| **Atelier** | the workshop where the craft happens | warm, but used by many products |
| **Relay** | hand-off between you, Claude and modules | generic, crowded name space |

## Logo directions (drafts in `docs/brand/`)
All three: one colour (`currentColor`, so they follow light/dark themes) + a single accent dot `#E0663A`, flat shapes, readable at 16 px, no gradients.

| | File | Rationale |
|---|---|---|
| A — Cairn | `brand/logo-a-cairn.svg` | three stones = tasks resting on dependencies; the accent dot = what to do now / the running agent. Pairs with the name *Cairn*. |
| B — Critical path | `brand/logo-b-path.svg` | three nodes on a rising path with a faded side branch = the graph and its critical path; the accent node = the goal. Works with any name. |
| C — Workbench | `brand/logo-c-bench.svg` | a panel split in work areas with a live indicator = one place to work; closest to the app's layout. Works with any name. |
